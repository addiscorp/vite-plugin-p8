# vite-plugin-p8

PHP components in Vite, rendered by [P8](https://p8.addis.gg): a PHP runtime in Rust, compiled to WebAssembly.

```ts
// vite.config.ts
import p8 from 'vite-plugin-p8';

export default defineConfig({
  plugins: [p8()],
});
```

Not released yet. Follow https://github.com/addiscorp/vite-plugin-p8.
